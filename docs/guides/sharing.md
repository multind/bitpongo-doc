## Publish only what you intend to show

1. Open your own strategy from **List → Running**.
2. Use the bottom **Display** action. Read the publication notice and confirm.
3. The action changes to **Cancel display** when the strategy is publicly displayed.
4. Check the plaza/share page. Verify the strategy, owner avatar/name and the data being shown.
5. Use Cancel display when you no longer want it listed, then refresh the plaza to verify the result.

The display switch controls visibility; it is not the pause switch and does not enable/disable trading. A direct share link and plaza listing can have separate access behavior—do not treat a previously shared URL as confidential or assume copies disappear.

## Revenue and profile data

“Total revenue”, realized PnL and return percentage are different measures. DCA includes position valuation in its displayed return where available; F&G performance has realized-closure metrics. Compare the same strategy type and date range before interpreting a loss percentage next to an amount. A zero can mean no matching data, not a risk-free result.

The owner's avatar should use the current saved profile, not a static app logo. Update your [profile](account.md), save and refresh the public view if it still shows older data. Do not infer identity from an avatar alone.

## Share and download

Preview the share page before sharing/downloading an image. Images are a snapshot, so later changes to the profile, returns or visibility do not edit already downloaded copies. Never include private API information, personal account details or claims of guaranteed performance.

If a supposedly hidden strategy remains publicly listed, report its safe ID and the view/time to support. Do not toggle trading repeatedly to fix a visibility issue.
