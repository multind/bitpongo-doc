# Bitpongo documentation

Bitpongo helps users configure and monitor automated recurring investment strategies connected to supported exchange accounts.

This documentation focuses on safe setup, notification behavior, operational expectations, and deployment configuration. It does not provide investment advice or promise investment returns.

## Available guides

- [Configure Bark notifications](./notifications/bark.md) for trade results, strategy events, and operational alerts.
- Review the source or propose documentation improvements in the [Bitpongo documentation repository](https://github.com/multind/bitpongo-doc).

## Security principles

- Keep exchange credentials and notification keys private.
- Use restricted exchange API permissions and do not enable withdrawal permissions.
- Store deployment secrets outside source control.
- Verify strategy settings and available balances before enabling automation.
