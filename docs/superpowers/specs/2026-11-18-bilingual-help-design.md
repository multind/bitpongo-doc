# 中英文图文文档与 App 帮助中心

## 目标与范围

将 Bitpongo 文档从介绍和 Bark 指南扩充为可以完成实际操作的用户手册。英文与简体中文同等完整；已有繁体中文入口和文章保留，不把未完成的繁体内容宣称为完整翻译。沿用现有 Docusaurus、品牌和前端视觉风格。

帮助中心与文档项目共用文章来源，不再长期维护数据库中的另一套用户教程。本次不涉及真实下单测试、修改生产策略或发布服务器。

## 已核实的现状

- 文档项目位于 `/Volumes/ExternalDrive/Project/Code/github/bitpongo-doc`，已有英文、简体、繁体的介绍和 Bark 教程。
- H5 帮助页从 `/content/articles` 读取列表、摘要和正文；文章来自后端 `content_article` 表，初始内容由 V20 数据库迁移写入。
- H5 正文目前按纯文本渲染，不能直接展示图文文档；搜索历史独立存储，需保留账户隔离。
- 部分现有说明的菜单路径已落后于当前产品，需要逐项按当前前后端实现核对。

## 方案比较与选择

1. 只补数据库文章：改动少，但无法解决双份内容、图文展示和长期维护问题。
2. 文档统一维护，帮助中心接入：推荐方案，用户已选择。App 保留帮助入口、分类、搜索和当前应用的样式；详细教程使用文档站的图文页面。
3. 引入独立 CMS：当前没有必要，增加管理后台、认证和部署负担。

## 内容目录

### 用户指南

- 快速开始：产品能力、注册与验证邮箱、登录和首次使用路线。
- 交易所连接：API 配置入口、现货/合约权限区别、IP 白名单、安全原则和连接失败排查。
- DCA 定投：创建流程、分配比例、每轮金额、执行频率、策略时区、价格区间、逢低买入、暂停与停止、成交和收益。
- F&G 策略：创建条件、每个实际字段、开仓和平仓规则、止盈止损、回撤公式及示例、交易周期如何计数。参数含义必须与当前后端一致，未核实的行为不写成承诺。
- 行情与价格提醒：K 线选价、交易对精度、五步创建、有效期、触发条件和提醒状态。
- 通知渠道：App、邮箱、Telegram、Webhook；Bark 作为历史/可选渠道解释，不作为所有用户的必需依赖。
- 感知与确认：强度顺序、五分钟未确认后的下一渠道、确认后停止升级的实际规则。
- 收件箱与提醒日志：区别、确认、筛选、分页和失败排查。
- 策略广场与分享：展示、取消展示、收益口径、头像与公开信息。
- 账户与偏好：资料、头像、地区、语言、显示时区、安全、会话、邮箱和注销。
- 故障排查与 FAQ：未执行、交易失败、余额不足、最小订单、无成交记录、无图表、推送未收到、验证码和版本更新。

### 运维指南

单独放置部署、邮件、FCM/APNs、Telegram/Webhook 配置和诊断步骤，明确与普通用户设置的区别。只给变量名和脱敏示例，不包含真实凭据、设备 Token 或服务器私密信息。

## 图文规范

- 核心教程采用“入口 → 截图标注 → 操作步骤 → 参数说明 → 成功结果 → 常见问题”的结构。
- 截图来自当前版本真实界面，用安全的演示数据；不触发真实交易、不改生产账户、不展示邮箱、API 密钥、余额等私人信息。
- 注册、API 配置、DCA、F&G、五步价格提醒和通知设置均需实际配图，不能用一张通用示意图充当全部教程。
- 中英文截图优先各自语言；缺少可安全获取的截图时使用明确标为“操作示意”的图，不伪造实测结果。
- 配图有标题、替代文本、编号和响应式宽度，手机上可读。复杂规则用流程示意图辅助，避免纯装饰图和收益承诺。
- 图片资源保存在文档仓库，记录对应页面和截图版本；后续更新可定位失效截图。

## 帮助中心接入

- 文档构建导出可公开访问的帮助索引：稳定 ID、语言、分类、标题、摘要、搜索文本和文档路径。只收录用户指南，不收录内部规格、计划或运维机密。
- H5 使用此索引提供分类和搜索，详细文章链接到相应语言的文档页，避免在 App 中另外实现一套 MDX 渲染器。
- 文档基础地址通过配置接入；实际域名/路径在部署前核实，不猜测已上线地址。
- 链接限定到配置的可信文档来源，索引仅允许合法相对路径；索引版本、缓存、跨域和超时规则在执行计划中确定。
- 文档暂不可用时显示清楚的重试提示和已有简短帮助作为降级；不将旧内容误标为最新。搜索历史仍使用现有后端接口并保留账户隔离。
- 对暂未完成的语言明确回退到英文；中英文文章 ID 和主题保持一致。
- 不删除生产数据库文章、不修改已执行的历史迁移，保留现有文章接口以兼容旧客户端及文章栏目。

## 验证与交付

- 每个操作路径和参数依据当前代码核实；外部平台配置步骤以官方说明为准。
- 中英文目录与文章配对检查、图片存在性、链接检查、帮助索引检查、TypeScript 和 Docusaurus 全语言生产构建。
- 保留现有 `docs.exclude: ['superpowers/**']`，检查构建产物确实不包含内部规格、计划和私密运维材料，而不只是从帮助索引中移除。
- H5 测试覆盖分类、搜索、语言回退、文档失败降级、账户切换与历史文章兼容；构建并检查手机宽度下的图文排版。
- 交付具体文章和图片清单、验证结果及明确未完成项；独立提交文档和前端改动，不混入其他工作。
