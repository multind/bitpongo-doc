title: 从这里开始使用 Bitpongo
description: 完成注册与邮箱验证，分清策略交易和价格提醒，再开启自动化。
---

Bitpongo 通过你自己的交易所账户执行策略，并提供行情和提醒。**价格提醒不等于交易订单**，策略也不保证收益。本教程截图来自当前 H5 界面，使用本地演示数据，不是真实余额或投资业绩。

## 1. 注册并验证邮箱

![登录入口，中文演示界面](/img/guides/login-zh.png)

1. 打开 App 或在线应用，选择「创建账户」。
2. 填写本人可接收邮件的邮箱，获取验证码，检查收件箱和垃圾邮件。
3. 使用本次注册请求对应的最新验证码。旧验证码、过期验证码、找回密码的验证码不能混用。
4. 完成注册后登录。不要向任何人提供密码或验证码，包括客服。

以后使用手机号或第三方登录时，如果账户没有经过验证的邮箱，需要先绑定并验证，才能可靠使用邮件提醒和邮箱找回功能。

## 2. 根据目的选择功能

| 你想做什么 | 从哪里开始 | 实际作用 |
| --- | --- | --- |
| 按时间买入币种 | [定投策略](dca.md) | 根据计划发起现货订单，受余额和交易所规则限制 |
| 根据信心指数交易 | [F&G 策略](fng.md) | 满足执行条件时发起受支持的合约交易 |
| 只关注价格、不下单 | [价格提醒](price-alerts.md) | 生成收件箱事件并通过所选渠道通知 |
| 接收交易与运行消息 | [App 通知](app-push.md) | 同时配置系统权限、设备和账户偏好 |

## 3. 开始前的安全检查

需要交易时再添加 [交易所 API](exchange.md)，**不要开启提现权限**。核对账户类型、可用余额和最小下单金额。配置至少一种通知方式，并用测试消息确认真正能收到。

## 怎样算准备完成

- 能正常登录和打开个人资料。
- 交易策略已选择有效 API，账户有足够余额。
- 策略的时间、方向和风险参数符合自己的设定。
- 测试通知实际到达接收端，而不只是显示「已入队」。

遇到问题先看 [故障排查](troubleshooting.md)。订单结果不明确时，不要反复创建策略或盲目重试下单。
