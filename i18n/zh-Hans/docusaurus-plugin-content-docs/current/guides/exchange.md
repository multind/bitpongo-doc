## 开始前

在交易所官方账户设置中创建 API。你需要自行确认所在地区和账户有权使用对应交易所与交易产品。Bitpongo 支持连接不等于交易所允许所有地区使用。

![添加交易所连接，演示界面](/img/guides/exchange-zh.png)

## 添加连接

1. 打开「我的 → API 管理」，新增连接。
2. 选择当前应用提供的交易所，设置容易识别的名称，例如「我的现货账户」。
3. 原样复制 AccessKey 和 SecretKey，不要带空格；仅在所选交易所要求时填写额外口令。
4. 保存后检查连接或余额。不要截图暴露未遮罩的密钥。

| 使用场景 | 在交易所核对什么 |
| --- | --- |
| 定投现货买入 | 查询/账户和现货交易权限，现货账户 USDT 余额 |
| F&G 合约交易 | 受支持的 USDT 合约权限、合约余额和持仓模式 |
| 所有交易 | 密钥有效性、服务器 IP 白名单、账户限制、正式/测试环境 |

**不要开启提现权限。** 建议单独创建 Bitpongo 专用 API。如果设置 IP 白名单，需要填写后端服务器实际出口 IP，而不是手机 IP；更换服务器后也要检查。

## 如何确认成功

API 管理中能看到连接，并可在对应策略创建页选择。现货余额查询成功，**不能证明合约权限正常**。

## 常见问题

- 「API-key、IP 或权限无效」：分别检查密钥、白名单和交易权限，不要只检查其中一项。
- 余额为 0：确认资金在现货还是合约钱包，以及是否被挂单冻结。
- 小额订单失败：看分配到每个币种的金额、精度和交易所最小订单规则，不只看策略总金额。
- 密钥泄露：先到交易所禁用，再更换应用里的连接。不要把密钥放到日志或聊天中。
