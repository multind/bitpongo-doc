## 只公开自己希望展示的内容

1. 从「列表 → 运行」打开自己的策略。
2. 点击底部「展示」，阅读公开说明后确认。
3. 开启后按钮会变为「取消展示」。
4. 去策略广场/分享页核对策略、所有者头像名称和公开数据。
5. 不再希望展示时取消展示，再刷新广场确认结果。

展示控制的是公开可见性，不是暂停开关，也不控制交易启停。直接分享链接和广场列表可能有不同的访问行为；不要把已经分享的 URL 当作秘密，也不要认为取消展示会删除别人保存的副本。

## 收益与头像

总收益金额、已实现收益、收益率并不是同一指标。定投在有数据时包含仓位估值，F&G 绩效包含平仓后的已实现指标。比较亏损比例和金额前，先核对策略类型、时间范围和口径。显示 0 可能是没有对应数据，不代表没有风险。

头像应该跟随已保存的个人资料，而不是固定的 App Logo。修改 [个人资料](account.md) 后保存并刷新公开页面，仍异常再反馈。头像本身不能用来确认真实身份。

## 分享与下载

分享或下载前先预览。下载图片是当时的数据快照，之后修改头像、收益或展示状态，不会修改已经保存的图片。不要公开 API 信息、私人账户资料或保证收益的宣传。

关闭展示却仍被公开列出时，提供安全的策略 ID、页面和时间反馈，不要通过反复启停交易来处理展示问题。
