F&G 策略根据恐惧贪婪指数观察值产生**受支持的合约交易信号**，不等于单纯的指数提醒订阅。合约与杠杆可能造成重大损失，止损条件不保证成交价格。

![F&G 创建页，参数为演示值](/img/guides/fng-zh.png)

## 创建前提

打开「列表 → 策略 → F&G 策略」，选择受支持的 API 和交易对，填写名称与参数。确认合约权限、合约钱包保证金和要求的单向持仓模式；服务端也需要开启合约执行能力。界面显示运行中，不代表马上有新信号可以下单。

## 参数与后端逻辑对应

| 参数 | 实际含义 |
| --- | --- |
| 下限 L / 下限区间 dL | 下方触发带是 `[max(0, L − dL), L]`，包含端点 |
| 上限 U / 上限区间 dU | 上方触发带是 `[U, min(100, U + dU)]`，包含端点 |
| 基础金额 B | 用于仓位计算的基础保证金，单位 USDT |
| 增幅比例 r | 下方区间金额 `B × (1 + r/100)`；上方区间 `B × (1 − r/100)`；倍率限制为 0.1–10 |
| 策略方向 | 做多使用下方区间信号，做空使用上方区间信号 |
| 杠杆倍数 | 当前校验为 1–20 倍，不代替保证金风险控制 |
| 交易周期 | 1–10,000 的正整数，按已完成的持仓交易轮数计数，不是采样或开仓尝试次数 |
| 止盈目标类型 | PERCENT 按相对保证金的浮盈百分比；USDT 按浮盈金额 |
| 止盈目标 | 对应所选类型的触发阈值 |
| 盈利回撤比例 | 从历史最高正浮盈百分比回落的相对比例 |
| 止损比例 | 相对保证金的亏损百分比；浮盈率小于等于该负阈值时触发 |
| 最大订单数 | 同时在处理中的订单执行状态数量，不是历史成交总数 |
| 最大持仓数 | 同时待开仓、持仓、平仓及待核对状态的仓位数量 |

例如下限 25、下限区间 5、上限 75、上限区间 5，触发带是 **20–25 和 75–80**，不是所有小于 25 或大于 75 的值。同一区间连续的新观察值不会每次轮询都重复开仓；观察时间还要晚于启用/更新策略的时间和上一条已处理数据，过期数据不能充当新信号。

## 为什么浮盈 20%、回撤 5% 会在 19% 触发

公式是：**最高浮盈率 ×（1 − 回撤比例 / 100）**。因此 `20% × 0.95 = 19%`，不是 15%。这是浮盈的相对回落，不是下降 5 个百分点。只要曾有正浮盈就开始追踪，**不等待达到止盈目标**。检查顺序为止损、止盈目标、盈利回撤。

## 下单、周期与暂停

当前实现使用市价开仓、只减仓市价平仓，然后核对实际成交。交易所受理不代表全部成交。部分成交需要继续核对，小额剩余受交易所规则影响，可能进入待复核状态；不能看到一笔平仓就认为整轮完成。

止盈、止损或其他原因的完整平仓经核对后，已完成轮数才增加；开仓失败不算。达到轮数上限后停止新开仓，提高上限也不会凭空生成新订单。暂停阻止新开仓，不等于现有仓位停止风险处理。删除、恢复或修改参数前，应查看成交记录和执行记录。

没有执行时依次检查：新指数数据、区间变化、策略方向、轮数/并发上限、执行能力和 [API 权限](exchange.md)。
