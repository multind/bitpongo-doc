## 几种记录有什么不同

| 页面 | 用途 | 不能单独证明什么 |
| --- | --- | --- |
| 收件箱 | 面向用户的触发消息和已读/确认状态 | 所有渠道都已送达 |
| 提醒日志 | 提醒事件历史和页面展示的状态 | 用户已经阅读 |
| 策略执行记录 | 评估、买入、跳过或失败原因 | 没有订单信息时不能证明交易所成交 |
| 成交记录 | 已记录的订单与成交 | 手机已经收到通知 |

## 查找并确认

1. 进入「提醒 → 收件箱」，使用页面提供的筛选或搜索。
2. 打开消息，核对交易对、规则/策略和事件时间。
3. 需要确认时明确确认该条事件，已读不等于确认。
4. 继续加载更多记录；列表分页，第一屏不是全部历史。

启用逐级感知后，确认会停止后续可用组的投递，不能撤回已发出的外部消息。不要把删消息或退出登录当作确认。

## 没记录或时间不一致

先清空筛选、核对登录账户，联网后刷新。比较带时区的真实时刻，不要只比几个小时数；策略执行时区与界面显示时区可能不同。较旧或被筛选的事件也可能不在当前页。

求助时提供 App 版本、带时区的大致发生时间、受影响页面、安全的记录 ID 和脱敏截图。不要提供 Token、API 密钥或完整 Webhook 地址。
