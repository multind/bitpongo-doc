## 设置强度

进入「我的 → 提醒方式 → 感知设置」，为 App、邮件、Telegram 和 Webhook 设置 **弱 → 中弱 → 中等 → 中强 → 强** 五档强度并保存。当前短信和电话不是可用的实际投递渠道。

强度决定投递顺序，**不代表铃声音量，也不代表获得 iOS 关键通知权限或能绕过专注模式**。渠道还需要已接入、已配置、已开启；按提醒选择渠道时，还要在该提醒的范围内。

## 开启确认升级时

![五分钟逐级感知和确认停止的流程示意](/img/guides/delivery-zh.svg)

1. 事件先发送到最低的可用强度。
2. 同一强度的渠道组成一组，同时进入该组投递。
3. 五分钟内没有明确确认，则安排下一个更高强度的可用组。
4. 直到用户确认或所有可用强度都发完。**不是每隔五分钟重发全部渠道。**

例如邮件为弱、Webhook 为中等：先发邮件，五分钟仍未确认才发 Webhook。若还配置并选择了更强的 Telegram，再经过下一确认窗口进入该组。网络和平台重试会增加延迟，不能把五分钟理解为精确到达承诺。

## 关闭确认升级时

关闭后，符合条件且被选中的渠道合并为一组发送，不再按强度逐级等待。

## 必须确认对应事件

进入 [收件箱](inbox.md)，查看消息并点击明确的确认入口。打开 App、看到横幅或标记已读，**不等于确认**。确认会阻止后续升级，但不能撤回平台已经接受或正在投递的消息。

某个渠道被跳过时，检查可用状态、开关、接收端、强度以及该提醒选择的渠道范围。也不要默认所有交易成功通知都走与收件箱提醒完全相同的确认流程。
