title: 创建和管理定投策略

定投是按照计划进行的**现货买入**，不保证降低成本或获得收益。下列金额仅解释参数，不构成投资建议。

![定投创建页，本地演示界面](/img/guides/dca-zh.png)

## 创建步骤

1. 进入「列表 → 策略 → 定投策略」。
2. 点击「买入币种」，选择 API 连接并填写容易识别的名称。
3. 设置「每期投入金额」和「币种配置」。例如每期 20 USDT，BTC/ETH 各 50%，理论上各分配 10 USDT，但每笔仍受精度和最小订单限制。
4. 设置定投频率和时间，核对「策略时区」，不要只看手机当前时间。
5. 有需要时设置「买入价格区间」；「逢低买入」是可选功能，可以不开启。
6. 创建/启用前核对现货可用余额、配置比例和最小订单金额。保存可能开始自动化，不要用真实资金试点表单。

| 参数 | 含义 | 填写时注意 |
| --- | --- | --- |
| 买入币种/比例 | 每期金额如何分配 | 分配后每笔都要满足交易所限制 |
| 每期投入金额 | 一次计划执行的预算 | 看可用余额，冻结资金不算可用 |
| 频率和时间 | 调度器何时评估买入 | 以保存的策略时区为准 |
| 买入价格区间 | 是否允许本次买入的价格条件 | 区间外不买入不一定是报错 |
| 逢低买入 | 可选的额外买入条件 | 关闭也是有效配置 |

## 执行时区与显示时区

例如策略保存为 `Asia/Shanghai` 的 21:00，即使旅行到其他地区，策略仍按该时区执行。界面可以把同一个时刻转换为显示时区，不要为了改变历史时间的显示而修改策略执行时区。采用夏令时的地区，一年中 UTC 偏移可能变化。

## 怎样确认真实成交

进入「列表 → 运行 → 策略详情」，对照「成交记录」和「执行记录」。触发/评估一次不代表交易所成交。收益曲线需要成交历史和资产快照，没有曲线也不能单独证明未成交。不确定时核对交易所订单。

「暂停」阻止之后的调度，不撤销已成交订单。「停止」是策略状态操作，**不等于卖出全部现货**。执行前阅读确认说明。

失败时先按 [排查指南](troubleshooting.md) 检查权限、余额和最小订单，再决定是否恢复。
