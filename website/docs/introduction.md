# Bitpongo Documentation

Bitpongo helps you connect supported exchange accounts, create automated recurring-purchase strategies, review positions and orders, and receive optional runtime notifications.

Bitpongo is a software tool. It is not a broker, custodian, exchange, or financial adviser. You remain responsible for your exchange account, credentials, strategies, and compliance with the rules that apply to you.

## Available guides

- [Configure Bark notifications](./notifications/bark.md)

## Security basics

- Only connect exchange accounts that you are authorized to control.
- Grant exchange API keys only the permissions required for trading.
- Never enable withdrawal permission on an API key used by Bitpongo.
- Treat exchange credentials and Bark push URLs as secrets.
- Test a strategy with a small amount before relying on automated execution.

More guides for exchange connections, strategies, account security, and deployment will be added here.
